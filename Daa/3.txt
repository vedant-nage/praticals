To write a Python program to solve the Fractional Knapsack Problem using a greedy algorithm.
Theory
The Fractional Knapsack Problem is an optimization problem in which we select items to maximize the total value without exceeding the knapsack's capacity.

The greedy strategy selects items in descending order of their value-to-weight ratio.

\text{Ratio}=\frac{\text{Value}}{\text{Weight}}

Algorithm
1. Start.
2. Accept the number of items, their weights, values, and knapsack capacity.
3. Calculate the value-to-weight ratio of each item.
4. Sort the items in descending order of their ratios.
5. Select items one by one:
   - If the entire item fits, add its weight and value.
   - Otherwise, take the fraction that fits and add its proportional value.
6. Stop when the knapsack is full or all items are considered.
7. Display the maximum value.
8. Stop.

Selecting items	O(n)
Overall time complexity	O(n log n)
Auxiliary space complexity	O(1) excluding sorting space

The Fractional Knapsack Problem was successfully solved using the greedy method by selecting items in descending order of their value-to-weight ratio to maximize the total value within the given capacity.

# Fractional Knapsack: Explanation and Viva Questions

## 1. Explanation of the program

The Fractional Knapsack Problem is an optimization problem in which we select items to maximize the total value without exceeding the capacity of a knapsack.

Unlike the 0/1 Knapsack Problem, we can take a fraction of an item.

The greedy strategy selects items based on their value-to-weight ratio.

\\[ \text{Ratio}=\frac{\text{Value}}{\text{Weight}} \\]

The item with the highest ratio is selected first because it gives the maximum value per unit of weight.

### Example

Suppose we have three items:

| Item | Weight | Value | Value/Weight |
| ---- | ------ | ----- | ------------ |
| 1    | 10     | 60    | 6            |
| 2    | 20     | 100   | 5            |
| 3    | 30     | 120   | 4            |

Knapsack capacity = 50

Step 1: Select Item 1 completely.

Remaining capacity = 50 − 10 = 40

Total value = 60

Step 2: Select Item 2 completely.

Remaining capacity = 40 − 20 = 20

Total value = 60 + 100 = 160

Step 3: Only 20 units of capacity remain, so take 20/30 of Item 3.

Value obtained = 120 × 20/30 = 80

Total value = 160 + 80 = 240

Therefore, the maximum value is 240.

## 2. Explanation of important Python statements

| Statement                                             | Explanation                                               |
| ----------------------------------------------------- | --------------------------------------------------------- |
| `items.sort(key=lambda x: x[1] / x[0], reverse=True)` | Sorts items by value-to-weight ratio in descending order. |
| `capacity -= weight`                                  | Reduces the remaining capacity after selecting an item.   |
| `total_value += value`                                | Adds the value of a completely selected item.             |
| `fraction = capacity / weight`                        | Calculates the fraction of an item that fits.             |
| `total_value += value * fraction`                     | Adds the proportional value of a partially selected item. |

## 3. Viva Questions and Answers

### Basic questions

1\. What is the Fractional Knapsack Problem?

It is an optimization problem in which we select items to maximize total value without exceeding the knapsack's capacity. Fractions of items are allowed.

2\. What is a greedy algorithm?

A greedy algorithm makes the best possible choice at each step based on the current situation.

3\. Why is Fractional Knapsack a greedy algorithm?

Because it selects the item with the highest value-to-weight ratio at each step.

4\. What is the value-to-weight ratio?

It is the value of an item divided by its weight. It represents the value obtained per unit of weight.

5\. What is the difference between Fractional and 0/1 Knapsack?

In Fractional Knapsack, we can take fractions of items. In 0/1 Knapsack, an item must either be selected completely or not selected at all.

### Algorithm-related questions

6\. Why do we sort items in descending order of their ratio?

To select the items that provide the maximum value per unit of weight first.

7\. What happens when an item does not fit completely?

We take the fraction that fits into the remaining capacity and add its proportional value.

8\. Why is the greedy method optimal for Fractional Knapsack?

Because selecting the highest value-to-weight ratio first always gives the maximum possible value for the available capacity.

9\. Can the greedy method solve the 0/1 Knapsack Problem optimally?

No. The greedy method does not always give the optimal solution for the 0/1 Knapsack Problem.

10\. What is the role of sorting in the program?

Sorting arranges items by their value-to-weight ratio so that the most profitable items are selected first.

### Complexity-related questions

11\. What is the time complexity of the program?

O(n log n), because sorting takes O(n log n) time and selecting items takes O(n) time.

12\. What is the space complexity?

The auxiliary space complexity is O(1) excluding the space used by sorting, because the algorithm uses only a fixed number of extra variables.

13\. What is the complexity of selecting items after sorting?

O(n), because each item is considered at most once.

### Practical-based questions

14\. What happens if the knapsack capacity is zero?

The maximum value is zero because no item can be selected.

15\. What happens if the capacity is greater than the total weight of all items?

All items are selected completely, and the total value is the sum of the values of all items.

16\. What happens if two items have the same value-to-weight ratio?

Either item can be selected first because both provide the same value per unit of weight.

17\. Can Fractional Knapsack be used in real-life applications?

Yes. It can be used in resource allocation, cargo loading, budgeting, and selecting materials when partial quantities are allowed.

18\. What is the main advantage of the greedy approach?

It is simple and efficient, providing an optimal solution for the Fractional Knapsack Problem in O(n log n) time.
