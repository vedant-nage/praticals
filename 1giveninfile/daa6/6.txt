Aim
To design an 8-Queens matrix with the first queen fixed and place the remaining queens using backtracking so that no two queens attack each other.
Theory
The 8-Queens problem requires placing eight queens on an \(8 \times 8\) chessboard so that no two queens share the same row, column, or diagonal.

The first queen is fixed at the top-left position, \((0,0)\). The algorithm places one queen in each subsequent row. Before placing a queen, it checks whether the position is safe.

If a placement prevents the remaining queens from being placed, the algorithm removes that queen and tries another column. This process is called backtracking.
Methods and Terms Used
- Backtracking: Builds a solution step by step and reverses a choice when it cannot lead to a valid solution.
- Safe position: A square not attacked by any already placed queen.
- Row-wise placement: Places one queen in each row, so row conflicts are avoided automatically.
- Column check: Ensures no two queens share a column.
- Diagonal check: Ensures no two queens share either diagonal.
- Base case: When all eight rows have a queen, a valid solution is found.
- Time complexity: Commonly expressed as \(O(N!)\) in the worst case for the standard backtracking search.
- Space complexity: \(O(N^2)\) for the board, with up to \(O(N)\) recursion depth.
Conclusion
The program fixes the first queen and uses backtracking to place the remaining queens. It checks columns and diagonals before each placement and removes queens from invalid partial arrangements until a valid 8-Queens matrix is found.
