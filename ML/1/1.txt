# Outliers

## 11. What is an outlier?

An outlier is a data value that is significantly different from the majority of the observations.

For example, an unusually high Uber fare may be an outlier.

---

## 12. How did you identify outliers?

We used **box plots** to visually identify potential outliers in:

- Fare amount
- Distance

We then used the **99th percentile** to remove extreme values.

---

## 13. What is percentile?

A percentile indicates the value below which a certain percentage of observations fall.

For example, the **99th percentile** is the value below which approximately 99% of the observations lie.

---

## 14. Why remove outliers?

Extreme values can negatively affect model training and evaluation. Removing unrealistic extreme values can help the model learn the normal relationship between features and fare.

# Correlation

## 15. What is correlation?

Correlation measures the strength and direction of the relationship between two variables.

Its value ranges from:

```text

```

- `+1` → strong positive relationship
- `0` → no linear relationship
- `-1` → strong negative relationship

# Linear Regression

## 18. What is Linear Regression?

Linear Regression is a supervised learning algorithm used to predict a continuous numerical value by finding a relationship between input features and the target.

In our practical, it predicts **Uber fare**.

---

## 19. What is the basic equation of Linear Regression?

For one feature:

**y = b₀ + b₁x**

Where:

- `y` = predicted value
- `b₀` = intercept
- `b₁` = coefficient
- `x` = input feature

With multiple features, it becomes:

**y = b₀ + b₁x₁ + b₂x₂ + ...**

---

## 20. What does Linear Regression try to minimize?

It tries to minimize the difference between actual and predicted values, commonly using **Mean Squared Error (MSE)** during fitting.

---

# Random Forest

## 21. What is Random Forest Regression?

Random Forest Regression is an ensemble machine-learning algorithm that uses **multiple decision trees** to make a prediction.

The predictions from the trees are combined, typically by taking their average for regression.

---

## 22. What is a decision tree?

A decision tree makes predictions by repeatedly dividing data based on conditions on the input features.

For example, it can make decisions based on:

```text
distance > certain value?
hour > certain value?
```

---

## 23. What does `n_estimators=100` mean?


means the Random Forest creates **100 decision trees**.

More trees can improve stability, but they also increase training time.

---

# Evaluation Metrics

## 28. What is R²?

**R² (R-squared)** measures how well the model explains the variation in the target variable.

Its value is generally interpreted as:

- Higher R² → better performance
- R² close to 1 → model explains much of the variation
- R² close to 0 → model explains little of the variation

---

## 29. What is RMSE?

**RMSE = Root Mean Squared Error.**

It measures the difference between actual and predicted values.

**Lower RMSE = better model.**

RMSE gives more importance to larger errors because the errors are squared before taking the square root.

---

## 30. What is MSE?

**MSE = Mean Squared Error.**

It calculates the average squared difference between actual and predicted values.

**Lower MSE = better.**

RMSE is simply the square root of MSE.

---

## 31. What is MAE?

**MAE = Mean Absolute Error.**

It calculates the average absolute difference between actual and predicted values.

**Lower MAE = better.**

# Very Important Differences

## 33. Linear Regression vs Random Forest

| Linear Regression | Random Forest |
|---|---|
| Uses a linear relationship | Uses multiple decision trees |
| Simple model | More complex model |
| Fast to train | Usually slower |
| Works well for linear relationships | Can capture nonlinear relationships |
| Easy to interpret | Less easily interpretable |

## 35. What is overfitting?

Overfitting occurs when a model learns the training data too closely, including its noise, and performs poorly on new/unseen data.

---

## 36. What is underfitting?

Underfitting occurs when the model is too simple to properly learn the patterns in the data.
